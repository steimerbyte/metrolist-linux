## What was added to `proofs/ui`

`candidate.rs` gains two obligations (all previously proven text untouched):

1. `play_starts_radio(song_count: usize, source: QueueSource, play_all: bool)
   -> bool` — six-variant `QueueSource`, spec `play_starts_radio_spec` equal to
   the source predicate, contract consequences (`r ⇒ one song`, `r ⇒ List`,
   `play_all ⇒ !r`, `0 songs ⇒ !r`) and three rule lemmas
   (`lemma_play_all_is_never_radio`, `lemma_radio_needs_exactly_one`,
   `lemma_radio_needs_list`). Model deviation: the exec body tests the
   fieldless enum by variant because the derived `PartialEq` is opaque to
   Verus; the spec keeps `==`.
2. `PlaylistOrder::sort_mode` — minimal `SortMode`/`PlaylistOrder` enums,
   `sort_mode_spec`, the exec method with `ensures r == sort_mode_spec(self)`,
   and `lemma_default_only_none` + `lemma_album_unreachable`. The two `label`
   functions stay CANDIDATE (`&'static str`); the sorters stay OUT-OF-SUBSET.

`original.rs` was regenerated by `proofs/derive_original.py` (sha256 unchanged);
the script was not edited. Derivation is additive-only: the new enums, spec fns
and exec surface appear; the five new `proof fn`s are stripped. The file has
no trailing-newline change beyond the existing convention.

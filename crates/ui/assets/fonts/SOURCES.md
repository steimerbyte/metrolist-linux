# Bundled font sources

All fonts are redistributable upstream releases; the space-grotesk statics are
instances of the upstream variable font. Everything is licensed under the SIL
Open Font License 1.1 (OFL-1.1) and the full license texts sit next to the
binaries. Sources point at the Google Fonts repository
(<https://github.com/google/fonts>).
